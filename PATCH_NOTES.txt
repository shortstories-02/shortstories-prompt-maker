ShortStories v1.0.22 — View State Fix

Behavior:
1. First successful login opens Prompt Builder.
2. Browser refresh preserves the currently open section/form.
3. Logout remembers the section that was open.
4. On the next explicit login, that previous section is visible for 500ms, then Prompt Builder opens.
5. View state is stored in localStorage and does not overwrite the refresh state with Builder.
