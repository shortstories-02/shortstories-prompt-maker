ShortStories Mobile Sidebar UI v1.0.2 — Revision

Mobile sidebar navigation has been revised to a single vertical column.

On mobile:
- Account card remains above the navigation.
- All navigation items are stacked from top to bottom in one column.
- Navigation is no longer a two-column grid.
- Sidebar remains vertically scrollable.
- Clicking outside the sidebar closes it automatically.
- Escape closes the sidebar.
- Desktop layout is unchanged.
