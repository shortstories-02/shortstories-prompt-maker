ShortStories Mobile Sidebar UI v1.0.2 — Revision

Mobile sidebar navigation has been revised to a single vertical column.

On mobile:
- Account card remains above the navigation.
- All navigation items are stacked from top to bottom in one column.
- Navigation is no longer a two-column grid.
- Sidebar remains vertically scrollable.
- Clicking outside the sidebar closes it automatically.
- Escape closes the sidebar.
- Desktop layout is unchanged.


v1.0.3 — Session inactivity & customer email validation
- Mobile/web session now automatically signs out after 30 minutes without activity.
- Activity is shared between browser tabs via localStorage.
- Manual logout clears the inactivity timer/state.
- Customer email is validated in the admin form and again in the create-customer Edge Function.
- Invalid email formats are rejected before an account is created.
- Existing desktop/mobile UI remains unchanged.
